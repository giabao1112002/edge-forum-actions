Teams notifications

Use a “Send webhook alerts to a chat” workflow. Reply cards contain case ID, action, deadline and thread link; Learn accepted-answer cards contain case ID and answer link. Developer Community Closed - Fixed cards contain case ID and thread link. No customer reply text is sent. The webhook is stored locally without encryption. Clear the URL and save to remove it.

How to read the planner
  • Today: customer replies need attention now. Their next-business-day date is the final deadline.
  • Complete: a forum post was observed; CI closure is not verified.
  • Last known: refresh failed. Check the error shown on that case.
  • Dates: local timezone, weekends excluded, holidays not included.
  • Refresh: keep the popup open until it finishes. Background checks also run with the popup closed.

Always verify the full thread and CI notes. This extension does not post replies, close cases, or access SharePoint/Insider/CI.
